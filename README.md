# Rutas Galicia — datos públicos

Archivos que descarga la app **Rutas Galicia** (Releases de este repositorio):

- `galicia.pmtiles` — mapa de Galicia para usar sin cobertura (Release `mapa-AAAAMMDD`, el más reciente es "latest").
- `catalogo.json` — catálogo de rutas (Release `catalogo`).
- `zonas.json` — cuestas y rectas para running (Release `zonas`).
- `app/version.json` — versión mínima de la app.
- `web/` — página para abrir en la app las rutas compartidas con un enlace.
